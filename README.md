# CosmoCodexLtd/.github

Organisation profile and default community files for Cosmo Codex Labs, the research group of CosmoCodex Ltd.

| Path | Purpose |
|---|---|
| `profile/README.md` | The page shown at [github.com/CosmoCodexLtd](https://github.com/CosmoCodexLtd) |
| `profile/assets/` | Banner (light and dark) and the mark, as SVG with all lettering converted to outlines |
| `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` | Defaults for every repository in the organisation that has none of its own |
| `.github/ISSUE_TEMPLATE/` | Issue forms: citation or link error, reproducibility report, research question |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request checklist |
